\# SpendWise Project Instructions



\## Project



SpendWise is an Android personal finance application for recording and analyzing expenses, income and monthly budgets.



\## Technology



\* Kotlin

\* Android Studio

\* Jetpack Compose

\* Material 3

\* MVVM architecture

\* Room for local storage

\* Navigation Compose

\* ViewModel and StateFlow

\* Firebase only when cloud functionality is implemented

\* Gradle Kotlin DSL



\## Development rules



\* Work on one feature at a time.

\* Inspect existing files before creating new ones.

\* Reuse existing components whenever possible.

\* Do not add a library unless it is necessary.

\* Do not upgrade Gradle, Kotlin or Compose without explicit permission.

\* Do not modify unrelated files.

\* Keep UI components separate from business logic.

\* Use repository and ViewModel layers.

\* Avoid duplicated code.

\* Use clear and consistent names.

\* Add short comments only when the logic is not obvious.

\* Do not store API keys or secrets in Git.



\## Verification



After every implementation:



1\. Run the relevant Gradle build.

2\. Fix compilation errors caused by the change.

3\. Report which files were changed.

4\. Briefly explain what was implemented.

5\. Mention anything that still requires manual testing.



\## Git



\* Make small, focused changes.

\* Do not commit automatically unless asked.

\* Do not rewrite existing Git history.



\## Compact instructions



When compacting context, preserve:



\* Current implementation stage

\* Architecture decisions

\* Files changed

\* Build and test results

\* Unresolved errors

\* Next planned task
